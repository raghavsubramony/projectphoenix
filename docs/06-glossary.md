# Glossary

| Term | Meaning |
|------|---------|
| **ATPE** | Adaptive Torque & Power Engine — modular free-piston linear-generator hybrid with AI-based cylinder management |
| **AMLCE** | Adaptive Modular Linear Combustion Engine — alternate name for ATPE |
| **PCMRITMS** | Phase-Controlled Multi-Ring Inertial Torque Modulation System — phase-coordinated multi-rotor inertial torque buffer |
| **Free-piston engine** | Engine where pistons move linearly instead of driving a crankshaft |
| **Linear generator / alternator** | Extracts electrical energy directly from linear piston motion via magnets passing through coils |
| **Series hybrid** | Architecture where the engine only generates electricity; electric motors drive the wheels |
| **BSFC** | Brake-Specific Fuel Consumption — fuel used per unit of power output; lower is better |
| **HCCI** | Homogeneous Charge Compression Ignition — high-efficiency, temperature-sensitive lean combustion mode |
| **TDC** | Top Dead Center — piston's highest point; combustion timing reference |
| **NVH** | Noise, Vibration, Harshness |
| **Bounce chamber** | Compressed-gas spring that returns a free piston |
| **Opposed-piston design** | Two pistons per cylinder firing toward each other; naturally balanced |
| **Atkinson / Miller cycle** | Cycles with expansion ratio greater than compression ratio for higher efficiency |
| **EGR** | Exhaust Gas Recirculation — knock and NOx suppression |
| **DC Bus** | Shared direct-current electrical backbone connecting generators, inverters, battery, and motors |
| **SiC** | Silicon Carbide — semiconductor for high-voltage, high-efficiency inverters |
| **800V architecture** | High-voltage EV electrical system enabling lower current, lighter cables, faster charging |
| **LFP** | Lithium Iron Phosphate battery chemistry — thermally stable, long cycle life, lower cost |
| **NMC** | Nickel Manganese Cobalt battery chemistry — higher energy/power density |
| **BMS** | Battery Management System |
| **SoC** | State of Charge (battery) — also System on Chip (compute) depending on context |
| **TWC** | Three-Way Catalyst — converts CO, HC, NOx in petrol exhaust |
| **GPF** | Gasoline Particulate Filter |
| **EHC** | Electrically Heated Catalyst — speeds catalyst light-off at cold start |
| **OBD-III** | On-Board Diagnostics standard adding real-world emissions monitoring/reporting |
| **AUTOSAR** | Automotive software architecture standard required for global homologation |
| **FPGA / DSP** | Field-Programmable Gate Array / Digital Signal Processor — real-time control hardware |
| **IMU** | Inertial Measurement Unit (6-axis: accelerometer + gyroscope) |
| **KERS** | Kinetic Energy Recovery System (e.g., flywheel-based) |
| **AWD** | All-Wheel Drive |
| **SOP** | Start of Production |
| **MUV / SUV** | Multi-Utility Vehicle / Sport Utility Vehicle |
| **Round-trip efficiency** | Fraction of energy retained through a store-and-release cycle |
| **kJ** | Kilojoule — unit of stored energy (e.g., 118 kJ buffer capacity) |
